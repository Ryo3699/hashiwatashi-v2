## 読み方（盛らない）
- **素の Claude のまとめは、読みやすくて中身も良い**（p1 は「毛先は薄くしたくない」を NG として拾い、当日確かめることを4つ挙げた）。「AI に聞けば同じでは？」は半分当たっている
- 違いは3つ：
  1. **1回に2〜4問をまとめて聞く**（3人とも・箇条書きで「長さは？髪質は？」）。v2 は1回1問（コードで止める）
  2. **まとめに「施術の方向性」「おすすめ」が入る**（3人とも。例：p1「サイドの中間〜根元寄りや内側で量を調整」）＝AI が決める側に寄る。v2 は推測のヒントだけで、施術は言わない（作り手の「けっていしてほしくないかな」）
  3. **p1 で「すいてほしい」を「（量を減らしたい）」と書いた**＝v2 が防ぎたい言葉のずれを、そのまま美容師に渡している。v2 は「すいてほしい」の裏の悩み（横の広がり・顔が四角く見える）を隠れた悩みとして渡す
- 物差しは v2 の検査（「？」の数・決めた言い方）＝v2 の決まりで素の Claude を測っている。まとめの中身の良さ（美容師の役に立つか）は測っていない
- 回数は各1回。家でのケアは素の Claude でも3人中2人で聞き出せた（v2 は試し6回で3人とも）
