# 今のアプリ（v1）と新しいアプリ（v2）の違い — 11/7 にどちらで出すか選ぶための1枚

> 2026-11-07 未明に Claude が書いた。v1＝`~/projects/hashiwatashi`（11/3〜11/5）、v2＝このフォルダ（11/6 夜に仕様書から作った）。

## 違いは3行
1. **美容師に渡すもの**：v1 は「訳」（お客様の言葉・本当の中身・残したい物・未確認）＋「ずれやすい所」＋「切る前の一問」。AI は原因を言わない。v2 は「隠れた悩み」＋「なぜのヒント」（原因／家でのケア／髪質と髪型）。全部を推測として書き、ヒントごとにもとの答えを原文で添える。
2. **聞き方**：v1 は3〜5問で、「残したい物」を必ず聞く。2回目の来店で「先の話の鍵」が開く。v2 は多くて7問で、3つの角度を1回ずつ聞く（本物では4〜5問）。「避けたいこと」は聞かないので、本物の試しでは6回中5回取りこぼした。
3. **裏付けと出す準備**：v1 は確認ケース10件で、素の Claude 0/10 → ハーネス 10/10（各条件1回）。README・提出文・画面の録画まで揃っている。v2 は架空のお客様3人を本物の Claude で9回通し、9回とも完了条件を満たした。ただし比べる相手がいない。README・提出文・録画は無い。

## v2 で出す場合にかかること
- GitHub に公開リポジトリを作る（Ryo の決裁が要る）
- デモ動画のアプリ画面（v1 の c01〜c03 にあたる所）を撮り直す：Claude がやって約1時間
- README と提出文を v2 用に書き直す：Claude がやって約1時間。今ある物は全部 v1 の説明
- Ryo が画面と文面を確かめる：約30分
- 美容室の実写の撮影台本（`bwc_japan2026_shoot_salon_v1.md`）はそのまま使える。v2 の架空のお客様 p1 は、台本の「すいてほしいです」と同じ設定にしてある

## v2 にしかない良さ
- Ryo が講義の型で、仕様書から自分で決めて作り直した。講義4の「旅路（つまずき・やり直し）を見せる」に当てはまる話になる
- 「なぜ」のヒントが、お客様が実際に言った家でのケア（自然乾燥・アイロン・熱めのお湯）に結び付く
