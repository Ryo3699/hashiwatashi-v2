# 今のアプリ（v1）と新しいアプリ（v2）の違い — 11/7 にどちらで出すか選ぶための1枚

> 2026-11-07 未明に Claude が書いた。v1＝`~/projects/hashiwatashi`（11/3〜11/5）、v2＝このフォルダ（11/6 夜に仕様書から作った）。

## 違いは3行
1. **美容師に渡すもの**：v1 は「訳」（お客様の言葉・本当の中身・残したい物・未確認）＋「ずれやすい所」＋「切る前の一問」。AI は原因を言わない。v2 は「隠れた悩み」＋「なぜのヒント」（原因／家でのケア／髪質と髪型）。全部を推測として書き、ヒントごとにもとの答えを原文で添える。
2. **聞き方**：v1 は3〜5問。軽くしたい人には「残したい所はありますか？」を聞く（v1 の `kata/型.md`）。2回目の来店で「先の話の鍵」が開く。v2 は多くて7問で、3つの角度を1回ずつ聞く（本物では4〜5問）。「避けたいこと」は聞かないので、本物の試しでは6回中5回取りこぼした。2回目の来店の作りは無い。
3. **裏付けと出す準備**：v1 は確認ケース10件で、素の Claude 0/10 → ハーネス 10/10（各条件1回）。README・提出文・画面の録画まで揃っている。v2 は架空のお客様3人を、今の作りの本物の Claude で6回（1人2回）と画面から1回通し、7回とも完了条件を満たした（直す前の作りでも3回通った）。ただし比べる相手がいない。README・提出文・録画は無い。

## Claude の推し
**v1 で出す**。理由：締切（11/8 日曜 20:00）の前日の土曜の夜までに出し切る目標。v2 は撮影台本の組み直しまで要る（下）。v2 で出すなら、11/7 の昼までに決めれば、土曜の夜に間に合う見込み。弱点：v1 は Ryo が自分で確かめ切れていない作りのまま。v2 の「旅路」の話も使えなくなる。

## v2 で出す場合にかかること
- GitHub に公開リポジトリを作る（Ryo の決裁が要る）
- デモ動画のアプリ画面（v1 の c01〜c03 にあたる所）を撮り直す：Claude がやって約1時間
- README と提出文を v2 用に書き直す：Claude がやって約1時間。今ある物は全部 v1 の説明
- Ryo が画面と文面を確かめる：約30分
- **美容室の撮影台本（`bwc_japan2026_shoot_salon_v1.md`）は組み直しが要る**。S1 の「すいてほしいです」は v2 の p1 と同じ設定なので使える。ただし次の3か所は v1 にしかない機能に頼っている。
  - S6：Ryo の問いが、アプリの「切る前の一問」になっている。v2 には「切る前の一問」が無い
  - 0:30〜1:00 の画面 c01：「訳→ずれやすい所→切る前の一問」の流れ。v2 には無い
  - 1:35〜2:05 の画面 c03：「2回目の来店・先の話の鍵」。v2 には無い
  - v2 で出すなら、この約1分ぶんを「隠れた悩み＋なぜのヒント」の見せ方に作り直す
- 撮影を先にする場合：v1 の台本どおりに撮ると、v2 では S6 の意味が変わる。撮る前にどちらで出すかを決めておく方が安全

## v2 にしかない良さ

- 「なぜ」のヒントが、お客様が実際に言った家でのケア（自然乾燥・アイロン・熱めのお湯）に結び付く
